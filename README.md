# ParadigmProgr_Magistr

Директория Other не относится к выполнению задания
Выполнение практического задания

# 1. Запуск системы
Для запуска необходимо выполнить скрипт в терминале или среде разработки: python main.py

Либо же IDE запустить файл main.py

# 2. Основные возможности

id студентов и курсов ставится автоматически.

Добавление студентов/курсов: В меню выберите пункт 1 или 2.

Выставление оценок: В меню выберите пункт 3. Сначала система попросит ввести ID существующего студента и ID существующего курса, а затем саму оценку.

Удаление: Пункты меню 4, 5, 6 позволяют удалять записи. При удалении студента или курса, все связанные с ними оценки автоматически удаляются из системы (каскадное удаление).

Поиск: Пункт 7. Можно вводить как числовой ID, так и часть имени/фамилии или названия курса.

Отчеты: Пункт 8. Позволяет рассчитать средний балл по конкретному студенту, по конкретному курсу, а также выводит Топ-5 лучших студентов.

Сохранение и загрузка:

Пункт 9 сохраняет текущее состояние базы в файл data.json.

Пункт 10 загружает состояние из data.json (позволяет продолжить работу с того же места после перезапуска программы).

Пункт 11 экспортирует плоскую таблицу всех оценок в grades_export.csv (удобно для открытия в Excel).

# 3. Обработка ошибок
Система защищена от сбоев:

При вводе текста вместо чисел (ID или оценки) выводится сообщение об ошибке, программа не "падает".

Запрещено добавлять дубликаты ID.

Запрещено выставлять оценки несуществующим студентам/курсам.

Ошибки чтения/записи файлов обрабатываются и выводятся пользователю.
